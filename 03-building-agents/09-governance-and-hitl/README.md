# 09. Human Governance & Risk Mitigation

Thư mục này nghiên cứu các mô hình tương tác Người - Tác tử (HITL, HOTL) và các chốt chặn an toàn cấp doanh nghiệp.

## 📖 Danh Mục Tài Liệu
* [01_hitl_and_hotl_human_agent_interaction.md](01_hitl_and_hotl_human_agent_interaction.md):
  * **Phổ tự trị (The Autonomy Spectrum):** HITL (Chốt chặn đồng bộ), HOTL (Giám sát bất đồng bộ) và HOOTL (Tự trị tuyệt đối).
  * **Ma trận rủi ro vs tự tin:** Định lượng Task Risk Index và Agent Confidence Score, cơ chế leo thang tự động (Dynamic Escalation).
  * **Kiến trúc kỹ thuật:** Interrupt-Resume với máy trạng thái bền vững (Durable State Machine), Parameter Overriding, Progressive Autonomy.
  * **Tối ưu trải nghiệm:** Chống Approval Fatigue qua Context Distillation, Batch Approval và Two-Person Rule.
